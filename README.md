# המקום של השייח — טרקלין נרגילות

משאב FiveM לעסק הנרגילות "המקום של השייח" בשרת CypherCity.

* **המשאב עצמו:** התיקייה [`cyphercity-hookah`](cyphercity-hookah). מעתיקים אותה לתיקיית ה-resources בשרת.
* **הוראות התקנה והגדרה (עברית):** [`cyphercity-hookah/README.md`](cyphercity-hookah/README.md)
* **בדיקות:** [`cyphercity-hookah/tests/README.md`](cyphercity-hookah/tests/README.md)
* **הכנסת העסק למפה של המקום של השייח:** מנהל שרת מקליד `/hookahsetup` בתוך המקום, עומד בכל נקודה ולוחץ E. ההסבר המלא: [הצבת המקום במפה](cyphercity-hookah/README.md#הצבת-המקום-במפה-מתוך-המשחק--hookahsetup-הדרך-הקלה)
