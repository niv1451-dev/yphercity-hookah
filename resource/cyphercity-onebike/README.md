# One Bike: אופניים חשמליים לשרת CypherCity

משאב FiveM לאופניים החשמליים של One Bike, בנויים לפי התמונה: צמיגים שמנים, שחור־צהוב, ומדוושים כמו אופניים.
תמונות של המודל: [`docs/renders`](docs/renders). התמונה המקורית: [`docs/reference.jpg`](docs/reference.jpg).

## מה מוכן

* **המודל התלת־ממדי:** בנוי ב־Blender, מחובר לשלד של אופני החשמל של המשחק (Inductor) ומיוצא לפורמט של GTA.
  * שלד עם כל העצמות: גלגלים, כידון, מזלג עם בולם, זרוע אחורית, קראנק ודוושות.
  * התנגשויות (collisions) לשלדה ולגלגלים.
  * 5 רמות פירוט: מקרוב בפירוט מלא, ומרחוק בגרסאות קלות שלא מכבידות על השרת.
  * פנס קדמי שנדלק עם האורות, ופנס אחורי אדום.
  * צג דיגיטלי צבעוני ועגול על הכידון, שמאיר כל הזמן ומראה:
    * מהירות (25 קמ"ש) ומד עגול בצהוב.
    * רמת עזר (PAS 3).
    * סוללה, שעון, נורית פנס, ומד קילומטרים ונסיעה.
  * לוח כפתורים (+, −, M) ליד הידית השמאלית.
  * צבעים מהמשחק: השלדה בצבע הראשי (שחור) והחלקים הצהובים בצבע המשני (צהוב). אפשר לצבוע אותם מחדש במוסך.
* **קבצי ההגדרות:** `fxmanifest.lua`, `data/vehicles.meta`, `data/carvariations.meta`, `client.lua`.

## שלב אחד לפני ההתקנה: המרה לקבצי המשחק (Windows)

המודל מגיע בתיקייה `onebike-model-source` כקבצי XML של CodeWalker. את ההמרה האחרונה לקבצים בינאריים (`.yft` ו־`.ytd`) אפשר לעשות רק ב־Windows.

**דרך א: CodeWalker (חינמי)**
1. מורידים ופותחים את CodeWalker, ונכנסים ל־**RPF Explorer**.
2. פותחים את התיקייה `onebike-model-source`.
3. מייבאים את שלושת הקבצים עם **Import XML**:
   * `onebike.yft.xml`
   * `onebike_hi.yft.xml`
   * `onebike.ytd.xml`

   חשוב שהתיקייה `onebike`, עם קבצי ה־DDS, תישאר ליד הקבצים. ממנה נלקחות הטקסטורות.
4. מתקבלים שלושה קבצים: `onebike.yft`, `onebike_hi.yft`, `onebike.ytd`. מעתיקים אותם לתיקייה `cyphercity-onebike/stream`.

**דרך ב: Blender עם התוסף Sollumz ב־Windows**
1. פותחים את `onebike-model-source/onebike_gta.blend`.
2. מייצאים את האובייקט `onebike` ב־Sollumz בפורמט Native (בינארי).
3. מעתיקים את הקבצים שנוצרו ל־`stream`.

## התקנה

1. **בדיקה מקדימה:** השרת צריך לרוץ על גרסת משחק 2802 ומעלה, כלומר `sv_enforceGameBuild 2802` או גבוה יותר ב־`server.cfg`.
   הנסיעה והצליל לקוחים מאופני החשמל של המשחק (Inductor), שנוספו בגרסה הזאת.
2. מעתיקים את התיקייה `cyphercity-onebike` לתיקייה `resources` בשרת.
3. מוסיפים ל־`server.cfg` את השורה:

   ```
   ensure cyphercity-onebike
   ```

4. מפעילים מחדש את השרת, ומוציאים את האופניים בשם **`onebike`**.

## מה לבדוק בפעם הראשונה

* הגלגלים מסתובבים.
* הכידון והגלגל הקדמי פונים ביחד.
* הדמות יושבת נכון על האוכף ומדוושת.
* הבולם הקדמי עובד בקפיצות.
* הפנס נדלק בלילה.

אם משהו לא נראה טוב, צלם מסך ושלח לי יחד עם השגיאות מהקונסול (F8). אני אתקן לפי זה.

## כיוונונים

* **צבעים:** בקובץ `data/carvariations.meta`, בשדה `indices`. 0 = שחור, 88 = צהוב.
* **מהירות, תאוצה ובלמים:** כרגע לקוחים כמו שהם מה־Inductor. אם צריך, אפשר להכין לאופניים הגדרות נסיעה משלהם.

אחרי שמשנים קובץ: מפעילים מחדש את המשאב (`restart cyphercity-onebike`), מתחברים מחדש למשחק ומוציאים את האופניים מחדש.

## עריכה של המודל

המודל נבנה מקוד, ולכן אפשר לשנות בו מידות, צבעים ופרטים ולייצא מחדש.
הקבצים נמצאים ב־`onebike-model-source/scripts`:
* `build.py`: המודל עצמו.
* `export.py`: הייצוא ל־GTA.
* `render.py`: תמונות המודל.

את המסמך [`docs/MODEL_BRIEF.md`](docs/MODEL_BRIEF.md) אפשר לתת לאמן תלת־ממד, אם תרצה מתישהו גרסה מפורטת עוד יותר.
